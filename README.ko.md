# Simple Share (FTP/WebDAV)

한국어 | [English](README.md)

Simple Share (FTP/WebDAV)는 로컬 폴더를 FTP 또는 WebDAV로 간단하게 공유할 수 있는 Windows 트레이 유틸리티입니다.

현재 안정 버전: **v1.0.3**

## 주요 기능

- FTP / WebDAV 서버 선택
- 수신 포트 직접 설정
- 최초 실행 시 공유 루트 폴더 선택
- 익명 접속 또는 사용자 이름/암호 인증
- 트레이 메뉴에서 Windows 방화벽 관리
  - 현재 허용 상태 확인
  - 현재 실행 파일 허용
  - 허용 규칙 취소
- 프로토콜/상태별 트레이 아이콘
  - FTP 실행 / 중지 아이콘
  - WebDAV 실행 / 중지 아이콘
- 설정 창 타이틀에 현재 프로토콜 아이콘 표시
- 트레이 아이콘 더블클릭으로 설정 창 열기
- 시스템 트레이 상주
- 트레이에서 서버 시작 / 중지
- 트레이에서 공유 루트 폴더 열기
- 설정 관리 2차 메뉴
  - 설정 변경
  - 설정 백업
  - 설정 복원
  - 설정 초기화
- GitHub Releases 기반 프로그램 내부 업데이트
  - 다운로드 진행률 및 전송 용량 표시
  - SHA-256 검증
  - 다운로드 중 업데이트 취소
  - 안전한 실행 파일 교체
  - 교체 완료 후 5초 재시작 카운트다운
- 한국어 기본 UI / 영어 선택 가능
- Windows 시작 시 자동 실행 토글
- Windows x64 단일 실행 파일 배포

## 다운로드

최신 Windows 버전은 GitHub Releases에서 받을 수 있습니다.

- `SimpleShare.exe`
- `SimpleShare.exe.sha256`

배포 페이지: https://github.com/danhk0612/Simple-Share-FTP-WebDAV-/releases

## 빠른 시작

1. `SimpleShare.exe`를 다운로드해 실행합니다.
2. 최초 실행 시 FTP 또는 WebDAV, 사용할 포트, 공유할 루트 폴더를 선택합니다.
3. 익명 접속 허용 여부를 선택합니다. 익명 접속을 사용하지 않는 경우 사용자 이름과 암호를 입력합니다.
4. 최초 설정을 저장하면 선택한 서버가 시작됩니다.
5. 이후 트레이 아이콘에서 서버 제어, 방화벽 관리, 설정 관리, 언어 선택, 업데이트 확인, 종료 기능을 사용할 수 있습니다.

### 기본 포트

- WebDAV: `8080`
- FTP: `2121`

포트는 설정에서 자유롭게 변경할 수 있습니다.

### FTP 참고

FTP는 제어 연결 외에 별도의 데이터 연결을 추가로 사용합니다. Simple Share는 제어 포트 하나만 여는 방식이 아니라 `SimpleShare.exe` 자체를 허용하는 Windows 방화벽 **프로그램 규칙**을 생성합니다. 따라서 애플리케이션이 생성하는 FTP 데이터 연결도 같은 허용 규칙을 사용할 수 있습니다.

트레이 메뉴에는 다음 기능이 있습니다.

- 서버 상태 표시
- 서버 시작 / 중지
- 루트 폴더 열기

  - 상태 확인
  - 허용

  - 한국어

트레이 아이콘은 현재 선택된 프로토콜과 서버 상태에 따라 자동으로 변경됩니다. FTP와 WebDAV는 서로 다른 아이콘을 사용하고, 서버가 중지된 경우에는 회색 아이콘으로 표시됩니다. 트레이 아이콘을 더블클릭하면 설정 창을 바로 열 수 있습니다.

## 설정 파일

설정은 현재 Windows 사용자 기준으로 다음 경로에 저장됩니다.

```text
%APPDATA%\SimpleShareFTPWebDAV\config.json
```

설정 파일에는 프로토콜, 포트, 루트 폴더, 인증 정보, 언어, 자동 실행 설정 등이 저장됩니다.

설정 백업은 사용자가 지정한 JSON 파일로 저장됩니다. 백업 파일에는 설정한 암호가 포함될 수 있으므로 신뢰할 수 있는 위치에 보관해야 합니다.

## 인증 방식

### FTP

익명 접속을 사용하지 않는 경우 설정에 저장된 사용자 이름과 암호로 인증합니다.

익명 접속을 허용한 경우 사용할 수 있는 익명 사용자 이름은 다음과 같습니다.

- `anonymous`
- `ftp`

### WebDAV

익명 접속을 사용하지 않는 경우 설정한 사용자 이름과 암호를 이용한 HTTP Basic 인증을 사용합니다.

## 방화벽 관리

트레이 메뉴의 **방화벽 관리**에서 다음 작업을 할 수 있습니다.

- 현재 `SimpleShare.exe`에 대해 활성화된 Windows 방화벽 허용 규칙이 있는지 확인
- 현재 실행 파일에 대한 인바운드 허용 규칙 추가
- Simple Share 방화벽 허용 규칙 제거

허용 또는 허용 취소 작업에는 Windows 관리자 승인이 필요합니다.

## 프로그램 내부 업데이트

트레이 메뉴에서 **업데이트 확인**을 선택하면 최신 GitHub Release를 확인합니다. 새 버전이 있으면 설치 여부를 묻습니다.

업데이트를 시작하면 전용 진행 창에서 현재 단계, 다운로드 진행률, 다운로드 용량을 표시합니다. GitHub가 전체 파일 크기를 제공하지 않는 경우 잘못된 퍼센트를 표시하지 않고 진행 중 형태의 표시로 전환합니다.

다운로드 단계에서는 **업데이트 중단** 버튼 또는 창 닫기 버튼으로 취소할 수 있습니다. 취소하면 임시 파일을 정리하고 현재 버전은 변경하지 않습니다.

EXE 다운로드 후 `SimpleShare.exe.sha256`을 받아 SHA-256 무결성 검사를 수행합니다. 실제 실행 파일 교체 단계에 들어가면 안전을 위해 업데이트 중단 기능을 비활성화합니다.

검증이 끝난 새 실행 파일 자체가 임시 updater로 실행됩니다. 기존 Simple Share가 종료된 뒤 원본 `SimpleShare.exe`를 교체하고, 완료 창에서 이전 버전과 새 버전을 표시합니다.

완료 창에서는 **자동 재시작까지 5초** 카운트다운을 표시하며, **지금 재시작** 버튼을 누르면 즉시 새 버전을 실행합니다. 창의 X 버튼을 눌러도 새 버전을 재시작하도록 처리합니다.

## 빌드

필요 환경:

- Windows 10/11
- Go 1.25 이상

로컬 빌드는 다음 방법을 권장합니다.

```bat
build.bat
```

`build.bat`은 Go 모듈 준비, Windows 매니페스트 및 아이콘 삽입, `SimpleShare.exe` GUI 빌드를 수행합니다.

GitHub Actions에서는 Windows x64 실행 파일과 SHA-256 파일을 생성하며, Release용 커밋에서는 두 파일을 모두 GitHub Release에 첨부합니다.

## 보안 주의사항

- FTP 통신은 암호화되지 않습니다. 신뢰할 수 있는 내부 네트워크에서 사용하거나 VPN 같은 보호된 네트워크 계층과 함께 사용하는 것을 권장합니다.
- 현재 WebDAV는 HTTPS가 아닌 HTTP를 사용합니다. TLS 종료, VPN 또는 다른 보안 터널 없이 인터넷에 직접 노출하지 않는 것을 권장합니다.
- 익명 접속을 허용하면 인증 없이 설정된 루트 폴더에 접근할 수 있습니다.
- 설정한 루트 폴더가 서버를 통해 노출되는 파일 시스템 범위입니다.
- 현재 설정한 암호는 로컬 JSON 설정 파일에 평문으로 저장됩니다.
- 설정 백업 파일에도 암호가 포함될 수 있습니다.
- 업데이트 실행 파일은 교체 전에 GitHub Release에 함께 게시된 SHA-256 값으로 검증합니다.
- Windows 사용자 계정, 설정 파일, 백업 파일을 적절히 보호해야 합니다.
